# Privacy Policy — Lynx Engine

**Last updated: October 6, 2026**

## 1. Introduction

Lynx Engine is a game engine developed and distributed by Oscar Soirey in Canada.

This Privacy Policy explains how Lynx Engine handles information when you use the engine, its editor, its launcher, and its associated features.

Lynx Engine is designed to operate primarily on the user's local computer. The engine does not currently operate user accounts, telemetry, crash reporting, or automatic collection of hardware information.

## 2. Information We Collect

Lynx Engine does **not currently collect personal information through the engine**.

In particular, Lynx Engine does not currently collect:

- User accounts or account information;
- Usage telemetry;
- Crash reports;
- Hardware information for telemetry purposes;
- Persistent user or machine identifiers;
- Cookies used to identify users;
- Personal information for analytics purposes.

Lynx Engine does not require an account to use the engine.

## 3. Local Data

Lynx Engine creates and uses certain data locally on the user's computer, including:

- Game projects;
- Project files and source code;
- Editor settings;
- Local logs;
- Other files required for the engine and editor to operate.

This information is stored locally on the user's computer and is not automatically transmitted to Lynx Engine.

The location and contents of these files are generally controlled by the user.

## 4. Lynxie and Artificial Intelligence

Lynx Engine includes an AI-assisted editor feature called **Lynxie**.

The current implementation of Lynxie uses **Ollama locally on the user's computer**. AI processing therefore takes place locally when the user has configured Lynxie to use a local Ollama instance.

When Lynxie is used, it may provide the AI model with contextual information necessary to perform the requested task. Depending on the operation, this context may include:

- The user's prompts;
- Information about the Lynx Engine environment;
- Information about the current project;
- Project files;
- Source code contained within the project.

With the current local Ollama implementation, this information remains on the user's computer and is not transmitted to a remote AI provider by Lynx Engine.

Users are responsible for the information and content they provide to or make available to their local AI models.

## 5. Future AI Services

A hosted AI service specifically designed for Lynx Engine may be developed in the future.

Such a service is not currently part of the local Lynxie implementation described above. If a remote AI service is introduced, its use may be optional and users will be able to disable the service.

If the introduction of such a service changes how user data is transmitted or processed, this Privacy Policy will be updated accordingly before or when the relevant functionality is made available.

Additional terms or privacy information may also apply to such a service.

## 6. Git and GitHub

Lynx Engine's Git functionality is intended to work with **local Git**.

Lynx Engine does not currently collect or transmit users' Git data to Lynx Engine.

If users choose to connect their local Git repository to an external hosting service such as GitHub, that interaction is controlled by the user and is subject to the privacy policy and terms of the relevant third-party service.

Lynx Engine does not control how such third-party services process information.

## 7. Updates and Launcher

Lynx Engine may provide an updater that automatically installs new versions of the Lynx Engine launcher.

The launcher allows users to choose which version of the engine they want to use.

The update mechanism is intended to retrieve the files required for the launcher and available engine versions. Lynx Engine does not use the updater to collect usage telemetry, crash reports, hardware information, or user accounts.

## 8. Logs

Lynx Engine may generate logs for local debugging and operation.

These logs are stored locally on the user's computer and are not transmitted to Lynx Engine or to a third-party service.

Depending on their contents, local logs may contain technical information such as file paths or other information generated during engine operation.

Users should be aware that file paths on some operating systems may contain the local computer user's name.

## 9. Third-Party Services

The current version of Lynx Engine does not require users to create an account or provide personal information to Lynx Engine.

Certain features may interact with software or services controlled by third parties, including local software such as Ollama and external services that users voluntarily choose to use.

Third-party services operate under their own privacy policies and terms. Lynx Engine is not responsible for the data practices of third-party services.

Users should review the privacy policies of third-party services before using them.

## 10. Data Retention

Because Lynx Engine does not currently maintain a centralized user account or telemetry system, Lynx Engine does not maintain a centralized database of users' projects, source code, editor activity, or usage history.

Information stored locally by the engine remains on the user's computer according to the user's own storage and deletion practices.

## 11. Data Security

Lynx Engine is designed to keep user projects, source code, and other project data local to the user's computer unless a feature explicitly requires communication with an external service.

Users are responsible for securing their own computer, project files, backups, and locally installed third-party software.

No method of electronic storage or transmission can be guaranteed to be completely secure.

## 12. Children's Privacy

Lynx Engine is intended for a general audience and is not specifically directed at children.

Lynx Engine does not knowingly collect personal information from children through user accounts, telemetry, or similar collection mechanisms.

## 13. User Rights

Depending on the user's jurisdiction and applicable law, users may have rights concerning their personal information, including rights to access, correct, or delete information held about them.

Because Lynx Engine does not currently maintain user accounts or a centralized collection of personal information, there may be little or no personal information held by the developer that can be associated with a particular user.

For privacy-related requests or questions, users may contact the developer using the contact information below.

## 14. Changes to This Privacy Policy

This Privacy Policy may be updated when Lynx Engine's features, data practices, or applicable legal requirements change.

If a future feature introduces the collection, transmission, or processing of personal information in a way that materially changes this Privacy Policy, the policy will be updated to describe the relevant practices.

The date at the top of this document indicates when it was most recently updated.
