LYNXIE // AI ASSISTANT

Your engine, with an AI inside it.

Lynxie is the AI assistant integrated into Lynx. It is designed to understand the project, operate the development environment, write code, modify the world, and help take an idea all the way to a compiled game.

Explore capabilitiesModels

WHAT LYNXIE CAN DO

Not just a chatbot. An engine operator.

Lynxie can work across the same project you are working on. Instead of stopping at an explanation, it can use the tools available in the Lynx environment to make changes and carry out development tasks.

FILES

Manage files

Inspect project files, create and modify files, understand the existing structure, and keep project assets and scripts organized.

JS

Write JavaScript

Create gameplay scripts, edit existing code, connect behavior to Actors, and iterate on gameplay without leaving the editor.

SCN

Control the scene

Create and modify Actors, adjust properties, configure the world, and make scene changes from natural-language instructions.

VX

Work with terrain

Operate on terrain and voxel worlds, making large world-building changes without manually repeating every editor operation.

BUILD

Compile the game

Run the build workflow when changes are ready and help move from an edited project to a playable build.

MORE

And much more

Lynxie is intended to be a general development assistant. Its capabilities can grow as more engine tools and workflows are exposed to it.

A NATURAL WORKFLOW

Tell Lynxie what you want. Let it operate Lynx.

Instead of jumping between the file browser, editor, scripting tools and build system, you can describe a task at a higher level. Lynxie can inspect the current state, decide which operations are needed, perform them, and report what changed.

The goal is not to hide the engine. It is to make the engine faster to use while keeping every part of the project accessible.

MODEL FREEDOM

Choose the model that powers Lynxie.

Lynxie is not locked to a single AI model. The model can be selected, allowing the assistant to evolve independently from any one provider.

THE VISION

Lynxie should make the engine feel conversational.

Whether you are creating a small prototype or a large voxel world, the idea is the same: spend less time navigating tools and repeating mechanical steps, and more time describing what you want to build.
