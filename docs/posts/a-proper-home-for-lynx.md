Since the beta went out, I've had a very specific itch: Lynx needed a proper home on the web. So I took a short break from the engine to work on the website (don't tell the engine).

## Getting Lynx is simpler

The download page now points to the **Microsoft Store** listing for Windows x64, and there's a button to open it straight in the Store app. No more manual installer: Windows takes care of updates.

## Plugins have a page

There's a new [Plugins](plugins.html) page that reads the plugin registry straight from the main repo. You can search and filter by category, and each plugin links to its own GitHub repository and releases.

Want to share your own plugin? There's a form on that page: fill in the repository, a short description and a category, and it prepares a request for the registry. I review the entries before they show up.

## A devlog (hello!) and tutorials

You're reading the first result of that work. Devlogs live here, and a [Tutorials](tutorials.html) section is ready for step-by-step guides. Both use the same simple system: a Markdown file per post, with support for code blocks, images, GIFs and YouTube videos.

## Smaller things

- the toolbar was getting crowded, so the docs pages now live under a **Docs** menu
- the menu works on mobile too
