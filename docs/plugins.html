Send publish request opens a pre-filled GitHub issue on the main repo. Edit registry opens plugins.json in GitHub's editor: paste the copied entry in the array and GitHub creates the pull request for you. A GitHub account is required.

Before you publish

Your releases must be tagged v<plugin version>-<Lynx version>, for example v1.2.4-26.0.6 is plugin 1.2.4 built for Lynx 26.0.6. The launcher picks the highest plugin version whose Lynx version is lower than or equal to the selected engine, so a plugin for 26.0.1 works on 26.0.6.

The asset is the first .zip of the release, with plugin.json (and bin/) at the root or in a subfolder. Pre-releases are only offered when "Beta versions" is enabled. Tags of any other form are ignored.
