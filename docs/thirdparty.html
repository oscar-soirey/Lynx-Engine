THIRD-PARTY

Libraries inside Lynx

Lynx relies on open-source libraries. Each one has a single job and sits in one layer of the engine. HRL, the renderer, is built by the same author as Lynx.

HRL — Horizon Rendering Library

Renderer

The rendering library of Lynx. HRL is a 2D/3D cross-platform rendering API that sits on top of several graphics backends (OpenGL, Vulkan, Direct3D 11/12, Metal) behind one unified API. It has an explicit object model: scenes, cameras, viewports, meshes, sprites, materials, lights and post-process are created and destroyed by you.

EnTT

ECS registry

Stores components and drives the entity-component-system behind every Actor. Each Actor is bound to an ECS entity; components are identified by a stable hash of their type name.
